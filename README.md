# EEC-2027-year-book
The Citadel Chronicles — An interactive Game of Thrones–themed digital yearbook for Easwari Engineering College (Batch of 2027), built with Next.js (App Router), Tailwind CSS v4, and Supabase, featuring a 3D leather-bound flipbook, House sorting quiz, shareable House cards, Lord Eddard Stark guide, and single-page or full-tome PDF export.
